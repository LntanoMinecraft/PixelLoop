📖 项目简介

PixelLoop（灵动帧）是一款 Android 端的屏幕录制与视频转 GIF 工具，旨在为用户提供简单、直观且高效的移动端创作体验。

你可以使用它录制屏幕、导入本地视频，通过内置编辑器调整画面和播放参数，最终生成 GIF 动图，并保存或分享自己的作品。

✨ 功能特性

🎥 屏幕录制

- 使用 Android 系统屏幕录制能力捕获屏幕内容。
- 提供录制前倒计时。
- 支持录制过程中的状态展示。
- 支持通过快捷设置磁贴快速启动录制。

🎬 视频编辑

- 从设备本地导入 MP4 视频。
- 支持多种画面比例：自由比例、1:1、16:9、9:16 和 4:3。
- 通过时间轴调整视频起始与结束位置。
- 支持调整播放速度。
- 支持自定义 GIF 帧率与输出分辨率。

🎞️ GIF 生成

- 将视频片段转换为 GIF 动图。
- 采用本地编码方式，无需依赖云端转换服务。
- 支持最高 60 FPS 的帧率设置。
- 提供多种输出分辨率选项。
- 显示导出进度，并支持后台处理。

🗂️ 创作管理

- 使用本地作品库管理已生成的内容。
- 支持保存和分享 GIF。
- 提供多视频处理队列。
- 支持查看最近的创作记录。

🎨 界面体验

- 基于 Jetpack Compose 构建。
- 采用 Material Design 3 Expressive 设计语言。
- 支持动态取色与主题切换。
- 使用流畅的动画与现代化界面布局。
